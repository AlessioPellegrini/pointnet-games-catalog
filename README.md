# PointNet Games — Official Game Catalog & Repository

Questo repository contiene il catalogo ufficiale e i pacchetti di gioco per la piattaforma **PointNet Games** su WordPress.

## 📦 Struttura del Repository

```
pointnet-games-catalog/
├── catalog.json                  # Indice remoto letto dal plugin WordPress
├── packages/                     # Pacchetti Zip scaricati con 1-click dal plugin
│   ├── minesweeper-arcade.zip    # Pacchetto Minesweeper
│   └── mahjong.zip               # Pacchetto Mahjong Arcade v1.8.0
└── games/                        # Sorgenti dei giochi
    ├── minesweeper-arcade/       # Gioco HTML5 Minesweeper
    └── mahjong/                  # Gioco HTML5 Mahjong Arcade
```

## 🎮 Giochi Inclusi

### 1. Minesweeper (`minesweeper-arcade`)
- **Versione:** 1.8.1
- **Modalità:** Classica (Facile, Medio, Difficile, Estremo), Scalata Progressiva 18 livelli e 🎓 Scuola di Logica (Academy) con Esame Finale.
- **Caratteristiche:** Pan & Pinch-to-zoom engine, chording rapido, audio tattile, OLED dark mode, controlli touch avanzati (doppio tap su celle scoperte/arena o two-finger tap per alternare modalità, blocco zoom nativo del browser, quick long-press 230ms, rimozione immediata bandiera al tocco), modalità Didattica interattiva bilingue con scanner pattern tattici.

### 2. Mahjong Arcade (`mahjong`)
- **Versione:** 1.8.0
- **Modalità:** Scalata Arcade (330 livelli, Boss Fight a rotazione) e Modalità Classica Tradizionale 144 tessere a 2-tap a terra.
- **Tavole 144 Tradizionali:** Tartaruga (Shanghai), Grande Ziggurat, Fortezza Imperiale, Il Ragno.
- **Caratteristiche:** Shield Wards, Nastri Trasportatori, Jukebox Zen integrato, 100% solvibile matematicamente.
