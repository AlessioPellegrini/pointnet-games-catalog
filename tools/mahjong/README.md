# 🛠️ Mahjong Arcade — Development & Testing Tools

Questa cartella contiene gli strumenti di test, benchmarking e simulazione offline dedicati a **Mahjong Arcade**.

### Script disponibili:
- **`benchmark-difficulty.py`**: Esegue simulazioni monte-carlo e analisi euristica di solvibilità sui layout e sulla disposizione delle tessere per calcolare la curva di difficoltà e il bilanciamento dei 330 livelli.

> **Nota di distribuzione**: Questi file sono strumenti di sviluppo offline e non vengono inclusi nel runtime client-side installato sui siti WordPress.
